Planar Loco-Manipulation with LLM Planning

A framework for quadruped navigation and object pushing using LLM-based planning and learned manipulation policies.

📄 Paper 📦 Dataset 💻 Code

Abstract

The deployment of robotic systems in real-world environments with minimal external intervention remains challenging. We propose a planar loco-manipulation framework that enables quadruped robots to reason about and act on their environments to achieve task-specific objectives. The system integrates a fine-tuned LLM-based planner with learned low-level navigation and manipulation policies trained using synthetic data. We validate the framework across diverse loco-manipulation tasks, demonstrating improved efficiency and robustness.
